# Changelog

## 0.1.0 · 2026-10-31 · Preview

- Initial shareable Windows package of the Spotify Glass customization.
- Popup display, glass library/search, native queue integration, lyrics/settings bridge, title fitting, and volume controls.
- Local pre-install backups and configuration-aware uninstall.
- Editable source, baseline versions, third-party notices, and isolated installer tests.
- Further testing on other PCs and Spotify versions remains necessary.
